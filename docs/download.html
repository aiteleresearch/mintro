Download MINTRO for Windows.

The free, open-source crypto mining app for Windows 10 and 11. It installs in a few seconds, just for your Windows account and without admin rights, then opens on your desktop.

  1. 01Requirements

    What you need

    • Windows 10 or 11, 64-bit. MINTRO is a Windows app; there's no Mac, Linux or phone version.
    • Microsoft Edge WebView2. Built into Windows 11 and every up-to-date Windows 10, so there's nothing to install.
    • Memory. RandomX coins (Monero, Zephyr, Salvium) need about 2.5 GB of free RAM for full speed. With less, MINTRO switches them to a 256 MB light mode so your PC never swaps.
    • Any processor from the last decade. A graphics card is optional: with a discrete NVIDIA, AMD or Intel Arc GPU, MINTRO can mine GPU coins alongside.
    • A wallet address for each coin, which MINTRO can make for you in one click for Monero, Zephyr, Salvium and MYT.
  2. 02Install

    Install it in five steps

    1. Download the installer

      Press Download MINTRO above. The file is MINTRO-Setup-0.4.3.exe.

    2. Keep the file

      If your browser says it isn't commonly downloaded, choose Keep. In Edge that's …, then Keep, then Show more and Keep anyway.

    3. Open it: More info, then Run anyway

      Windows shows Windows protected your PC because MINTRO is new and not yet code-signed. Click More info, check that the app is MINTRO-Setup, then click Run anyway.

    4. Click Install

      MINTRO Setup installs it in a few seconds, adds it to the Start menu and opens it. Running the installer again later updates or repairs it.

    5. Add wallets and press Start

      A short welcome shows how MINTRO tuned itself to your PC and offers to create wallets. Then press the big Start button: MINTRO does the rest.

    Smart App Control, on some new Windows 11 PCs, blocks apps that aren't code-signed and offers no Run anyway, so MINTRO can't be installed on those PCs yet.

  3. 03Updates

    Updates install themselves

    MINTRO checks for a new version a few minutes after it starts and every six hours. It downloads the update, checks it was signed by MINTRO's publisher (anything else is refused), and installs it when you've been away from the PC for two minutes. Mining doesn't stop: the running miner is handed to the new version, which carries on with the same coin, pool connection and counters. If the new version doesn't start properly, the previous one comes back by itself.

  4. 04What's new

    What's new in MINTRO 0.4.3

    • A new installer: welcome, progress and a clear error screen with Try again. Run it again to update or repair; your settings and wallets stay.
    • A three-step welcome the first time MINTRO opens: how it tuned itself to your PC, what to expect, and one-click wallets.
    • The installer window sizes itself to your display scaling, so nothing is cut off at 125% or 150%.
    • Publisher details on both programs (aitele research, MINTRO, version), shown in Windows' file properties.
  5. 05Uninstall

    Uninstall any time

    Open Settings › Apps, find MINTRO and choose Uninstall. MINTRO's program is removed; your settings, earnings history and any wallets it made stay in %LOCALAPPDATA%\MINTRO, so you keep your coins. Delete that folder too once you've backed up your wallets' seed words.

  6. 06Open source

    Check it, or build it yourself

    MINTRO is free software under the GPL-3.0 licence. The app, this website and the release tools are on GitHub, so anyone can read exactly what the installer does, or build their own copy with py -3.12 setup\build.py.
