  1. 01Choosing

    How MINTRO picks your basket

    You don't pick coins by hand. MINTRO measures what your PC can do on each algorithm, then scores every coin from 0 to 100: higher when your PC would mine a bigger slice of the coin's new supply, when it has active miners, and when it either has real trading or no market yet (the earliest stage). It only keeps a coin if your PC would reach that coin's minimum payout on the pool within a week, so nothing sits stranded on the pool.

    Then it mines one coin at a time, twenty minutes per turn, and rotates so each coin gets its planned share. A laptop has one processor cache and a RandomX miner needs about 2.5 GB of memory, so running coins in turns beats running them side by side.

  2. 02Algorithms

    The algorithms, briefly

    RandomX
    Monero's proof of work since 2019, built to run best on ordinary processors: it executes random programs against a dataset of about 2 GB, which favours a CPU's cache and memory over special hardware. Monero, Zephyr, Salvium and several newer coins use it. Needs about 2.5 GB of free RAM for full speed; MINTRO drops to the 256 MB light mode when memory is short.
    RandomARQ and RandomWOW
    RandomX variants with different settings, made for ArQmA and Wownero and used by a few newer coins. Same engine, same CPU-friendly design.
    GhostRider
    Raptoreum's algorithm. It chains CryptoNight variants with a rotating set of classic hash functions, which keeps it hard to build special hardware for. Raptoreum and Babacoin use it.
    yespower, yespowerR16
    Memory-hard proof of work from the yescrypt family, designed to suit CPUs and resist GPUs and ASICs. Used by smaller coins such as Yenten.
    yescryptR32
    A yescrypt variant tuned for CPU mining; light on memory, so it runs on almost any PC.
    power2b
    yespower with BLAKE2b in place of SHA-256, used by MicroBitcoin.
    MinotaurX
    Combines the Minotaur hash with yespower, keeping CPUs competitive. Introduced by Litecoin Cash.
    FiroPoW and MeowPoW
    GPU algorithms from the ProgPoW family (Firo's FiroPoW, Meowcoin's MeowPoW). MINTRO mines them on a separate GPU lane with SRBMiner-Multi, only on PCs with a discrete graphics card.
  3. 03Engines

    The engines that do the mining

    • XMRig for RandomX, RandomARQ, RandomWOW and GhostRider. Its own developer fee is 1%.
    • cpuminer-opt for yespower, yespowerR16, yescryptR32, power2b and MinotaurX. No fee.
    • SRBMiner-Multi for FiroPoW and MeowPoW on a graphics card. About 0.85% fee.

    MINTRO downloads each engine from its project's official GitHub release and checks its fingerprint before the first run. MINTRO itself takes nothing: every share goes to your own address.

  4. 04Coin projects

    Want your coin here?

    Coin projects can apply to be listed, so every MINTRO PC can mine their coin with no setup on the miner's side, on the rplant pool or the project's own pool. Listings are always labelled, and featured coins show their guaranteed share of mining time. See the listing plans.
